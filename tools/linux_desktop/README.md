# Desktop entry

What the Linux package, oui-paint, adds to the desktop's menu of applications: OUI Paint's entry, in
/usr/share/applications, and its icon, in /usr/share/icons/hicolor/128x128/apps.

The icon is the one the program gives its window, `oui::text_icon` as `src/main.cpp` calls it, drawn at its 128 pixels
a side: a blue "P" on white. A change to the window's icon is made here too.
