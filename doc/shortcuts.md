# Keyboard and mouse

OUI Paint takes Paint.NET's keys, from Paint.NET's "Keyboard & Mouse Commands" page
(paint.net/doc/latest/KeyboardMouseCommands.html). A key listed here that does nothing yet waits for the step that
brings what it works on.

## Tools

Pressing a tool's letter again goes to the next tool that shares it.

| Key | Tool |
|---|---|
| S | Rectangle Select, then Lasso Select, Ellipse Select, Magic Wand |
| M | Move Selected Pixels, then Move Selection |
| Z | Zoom |
| H | Pan |
| F | Paint Bucket |
| G | Gradient |
| B | Paintbrush |
| E | Eraser |
| P | Pencil |
| K | Color Picker |
| L | Clone Stamp |
| R | Recolor |
| T | Text |
| O | Line / Curve, then Shapes (Shift+O: Shapes) |
| X | Swap the primary and secondary colors |
| C | Switch between editing the primary and the secondary color |
| [ and ] | Brush width down and up by 1; with Ctrl, by 5 |

## File

| Key | Command |
|---|---|
| Ctrl+N | New |
| Ctrl+O | Open |
| Ctrl+W, Ctrl+F4 | Close |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As |
| Ctrl+Alt+S | Save All |
| Ctrl+P | Print |
| Alt+F4 | Exit |

## Edit

| Key | Command |
|---|---|
| Ctrl+Z, Ctrl+Y | Undo, Redo |
| Ctrl+X, Ctrl+C | Cut, Copy |
| Ctrl+Shift+C | Copy Merged |
| Ctrl+V | Paste |
| Ctrl+Shift+V | Paste into New Layer |
| Ctrl+Alt+V | Paste into New Image |
| Delete | Erase Selection |
| Backspace | Fill Selection with the primary color |
| Ctrl+A | Select All |
| Ctrl+I | Invert Selection |
| Ctrl+D, Enter | Deselect |
| Arrows, Ctrl+arrows | Move the selection or the selected pixels 1 pixel, or 10 |

## View and images

| Key | Command |
|---|---|
| Ctrl++, Ctrl+- | Zoom In, Zoom Out |
| Ctrl+B | Zoom to Window (twice: center the image) |
| Ctrl+Shift+B | Zoom to Selection |
| Ctrl+0 | Actual Size |
| Ctrl+Tab, Ctrl+Page Down | Next image |
| Ctrl+Shift+Tab, Ctrl+Page Up | Previous image |
| Alt+1 … Alt+9 | Image 1 to 9 |
| Space+drag, middle drag | Pan |
| Wheel, Page Up, Page Down | Scroll up and down; Shift+wheel sideways |
| Home, End | Go to the top left and bottom right corners |
| Ctrl+wheel | Zoom around the pointer |

## Mouse

| Action | What it does |
|---|---|
| Left button | Paints with the primary color |
| Right button | Paints with the secondary color |
| Ctrl+drag, Alt+drag | Add to, subtract from the selection |
| Alt+right drag, Ctrl+right drag | Intersect with, invert the selection |
| Shift+drag | Keep a selection or a shape square or round |
| Color Picker: left, right, Ctrl+click | Primary color, secondary color, from the whole image |
| Clone Stamp: Ctrl+click | Where it copies from |
